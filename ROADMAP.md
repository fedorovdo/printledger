# Roadmap

This roadmap is a planning document, not a guarantee of delivery dates.

## v0.1.x Public MVP

- Stabilize the public repository structure.
- Keep Docker Compose development and production deployment working.
- Polish documentation for installation, backup, restore, and usage.
- Improve onboarding for first-time users and administrators.
- Continue tightening UI wording and table ergonomics.

## v0.2.x Better Operations

- Improve cartridge replacement workflows.
- Add richer operation filters and saved views.
- Add safer cleanup/deactivation workflows for old catalog records.
- Improve printer and cartridge history screens.
- Add more validation and conflict explanations in the UI.

## v0.3.x Multi-user And Roles

- Expand role permissions beyond `admin` and `user`.
- Add audit views for administrator actions.
- Improve user management and password policies.
- Add session/token administration tools.

## v0.4.x Reporting

- Add stock and usage reports.
- Add printer lifecycle reports.
- Add low-stock and purchase planning reports.
- Improve CSV export coverage.
- Prepare printable report layouts.

## v0.5.x Production Hardening

- Add deployment hardening examples.
- Improve backup retention workflows.
- Add monitoring and health-check documentation.
- Add upgrade and rollback playbooks.
- Review security defaults for public deployments.

## Future Ideas

- Barcode and QR support.
- Telegram notifications.
- LDAP or Active Directory authentication.
- API tokens.
- Excel import/export improvements.
- Monitoring examples.
- Scheduled backup examples.
- More granular permissions.
