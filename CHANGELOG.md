## [0.1.0] - TBD

### Added

- FastAPI backend.
- PostgreSQL database.
- SQLAlchemy 2.0 models and Alembic migrations.
- Next.js frontend with TypeScript.
- Docker Compose development stack.
- Production Docker Compose stack with nginx.
- Local-network authentication.
- Database-backed user management.
- Role-aware navigation.
- Admin-only backup management UI.
- Backup and restore scripts for Windows and Linux.
- Web backup create, download, restore, and delete flows.
- Printer inventory.
- Cartridge model inventory.
- Cartridge transaction journal.
- Stock-in, correction, install, remove, refill return, write-off, and return-to-stock operations.
- Printer lifecycle tracking for moves, repairs, archive, and write-off.
- Organization, branch, and location directories.
- Printer and cartridge detail cards.
- Dashboard status cards.
- Dashboard cartridge usage analytics.
- CSV export for cartridge usage analytics.
- RU/EN frontend localization.

### Notes

- `0.1.0` is the initial public MVP target.
