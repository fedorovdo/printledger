# PrintLedger: краткое руководство пользователя

## Вход в систему

1. Откройте `http://localhost:3000`.
2. Если вход еще не выполнен, система перенаправит на `/login`.
3. Введите логин и пароль администратора из `.env`.
4. После успешного входа откроется Dashboard.

Пароль по умолчанию из примера `admin123` нужно заменить перед использованием в локальной сети.

## Выход из системы

1. Нажмите кнопку `Выйти` в верхней панели.
2. Токен будет удален из браузера.
3. Для повторного доступа к страницам потребуется снова войти.

## О системе

Страница `О системе` доступна из верхнего меню или по адресу:

```text
http://localhost:3000/about
```

На странице показаны версия приложения, статус backend, статус базы данных, окружение и подсказка по документации.
