# Commercial Support

PrintLedger is open-source software. You can install, run, study, and modify it under the terms of the MIT License.

For organizations that want help with deployment or adaptation, paid services may be available.

## Services

- Installation on a local or hosted Linux server.
- Docker and Docker Compose deployment.
- nginx and reverse proxy setup.
- HTTPS setup.
- Backup and restore setup.
- Migration from Excel-based inventory files.
- Custom fields and workflow adjustments.
- Custom reports.
- Administrator and user training.
- Ongoing support and updates.

## Scope

Commercial support is intended for practical implementation work around PrintLedger. It does not change the open-source license or remove the ability to self-host the project independently.
